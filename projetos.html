Projetos

Ao longo dos anos, consegui desenvolver algumas aplicações Web e listarei as mais relevantes:

Extração de dados sobre Fundos Imobiliários

Esta aplicação foi desenvolvida com Python e Docker e não possui interface gráfica.

O objetivo era conseguir extrair informações sobre Fundos de Investimento Imobiliário (FIIs).

Para obter os dados, um webscrapper foi usado para acessar a interface da Bovespa e também a API chamada AlphaAdvantage.

Como o processo de extração era lento, ele era dividido em etapas para que não houvesse perda de informação durante as fases.

Uma wiki simplificada sobre Django

Criar aplicações com o framework Django (em Python) permite agilizar várias etapas do processo de desenvolvimento.

Entretanto, às vezes eu tenho dificuldades em recordar algum conceito e acabava gastando tempo pesquisando novamente sobre o assunto.

A partir desse problema, criei essa Wiki - que pode ser acessada aqui.

O objetivo nunca foi substituir a extensa documentação do framework, mas oferecer uma rápida solução para problemas que eu já enfrentei.

Um sistema para controle de treinos de musculação

Durante os treinos de musculação, eu sentia falta de uma ferramenta simples para controle das cargas usadas.

Apesar de existirem vários sites e aplicativos por aí, eu percebia que era difícil algum serviço oferecer a opção de exportar os dados e, consequentemente, reutilizar os dados em outro serviço.

A partir dessa necessidade, criei esta aplicação super simples. Ela não possui nenhum servidor, salvando todas as informações no localStorage do navegador.
